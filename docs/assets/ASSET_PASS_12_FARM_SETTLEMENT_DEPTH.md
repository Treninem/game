Goal: deepen the usable asset library without indiscriminately collecting files. Prefer CC0, game-ready assets that close a concrete gameplay/environment gap.

## Import rules
1. Confirm license at the original creator/source before importing binaries.
2. Prefer glTF/GLB for runtime; retain FBX/Blend source only when useful for editing/animation.
3. Record source URL, author, license, original pack name and modifications.
4. Do not import redundant low-quality variants just because they are free.
5. Keep style compatibility, scale, pivots, collisions, material count and texture memory in mind.
6. Generate a missing asset locally when a coherent custom asset is better than mixing an incompatible pack.
