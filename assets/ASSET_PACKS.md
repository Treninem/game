# ImPuls Game — Shared Asset Pack Registry

Canonical asset registry for every development chat/agent working on this game.

## Mandatory cross-chat rule
Before generating or importing art, check this registry and the `assets/` tree. Reuse approved assets first. If missing, search free/CC0 sources; generate project-owned assets only when no suitable pack exists. Record source/license for every import.

## Import policy
1. Prefer glTF/GLB for Godot when available; retain source/license metadata.
2. Do not dump entire huge archives into Git blindly. Import only useful game-ready content and optimized runtime variants.
3. Deduplicate meshes/materials/textures/animations shared across packs.
4. Normalize scale, orientation, collision, material naming and LOD conventions before production use.
5. Keep art direction coherent: recolor/rematerial compatible CC0 assets where necessary rather than mixing visibly incompatible styles.
6. Third-party pack folders get `SOURCE.md`/`LICENSE.txt` metadata before assets are treated as production-ready.
