# Source chat B31 — real CC0 prototype/animation and pirate libraries

Real source assets only; nothing is connected to gameplay.

Prototype Kit provides a broad fallback library for characters/animations, animals, wheelchair, vehicles, structures, buttons/levers and general objects. Pirate Kit provides ships, treasure, island/nature and themed props.

Main chat should treat Prototype Kit primarily as an animation/prototyping/fallback source and only promote art-direction-compatible assets to production. Pirate assets should be selected for ports/coasts/islands where they fit the world.
