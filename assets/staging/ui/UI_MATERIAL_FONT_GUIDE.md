# UI materials and fonts

Source-only staging for interface styling.

Material roles:
- dark_wood / cedar: wooden frames, crafting, settlement and neutral RPG panels.
- leather: inventory, equipment, survival and journal covers.
- rusty_iron: workshop, industry and technology-era screens.
- obsidian / onyx: magic, rare/premium and dark UI accents.
- white_marble: palace, government and high-status screens.
- parchment_wallpaper: maps, journals, quests and codex backgrounds.

Font roles:
- Rubik: preferred primary readable UI font.
- PT Serif: preferred long-form book/journal/lore font.
- Old Standard TT: decorative/historical headings and documents.

All three font families have verified Cyrillic coverage and OFL source files staged alongside them.
