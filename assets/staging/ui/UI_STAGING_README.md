# UI staging

Source-only UI assets for menus, maps, HUDs, inventory and decorative interface work.

- kenney_ui_pack: broad default UI system.
- kenney_ui_pack_adventure: fantasy/adventure UI system.
- kenney_game_icons / kenney_board_game_icons: map, inventory, settings and systemic icons.
- kenney_input_prompts: keyboard/mouse/controller glyphs.
- kenney_cursor_pack: cursor and pointer variants.
- simple_button_pack: fallback button/tab states.
- rpg_inventory / rpg_inventory_icons: inventory, loot and crafting UI.
- rpg_ui_icons / map_editor_ui_icons: status, magic, map and compact systemic icons.
- map_marker_active / map_marker_normal: vector world-map POI markers.
- parchment_map_texture: map/journal background.

Main integration chat should review style fit and copy only selected assets into production UI folders.
