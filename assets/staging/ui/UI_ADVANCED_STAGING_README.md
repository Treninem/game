# Advanced UI staging

Source-only CC0 options for HUD, map, quest, journal, progression and RPG systemic interface.

Recommended style groups:
- Hand-painted/adventure: fantasy_rpg_icons_handpainted*, scroll_ui_container, epic_book_ui, fantasy_map_scroll.
- Broad neutral/systemic: health_mana_ui, experience_bar, quest_exclamation_icon, document_icons_scalable.
- Pixel/fallback: tiny_rpg_dragon_regalia_gui, fantasy_units_skills_icons, rpg_496_icons, parchment_gui.

Do not mix all style groups on one screen. Main integration chat should choose a coherent family per UI layer.
