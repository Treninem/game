# System G6 — verified CC0 source packs

These are original downloadable archives mirrored into the repository for the main game-development chat to inspect, unpack, normalize and selectively integrate.

This research chat does not wire these assets into scenes, scripts or project settings.

Included packs:
- Medieval Tools Pack — 12 low-poly tools.
- Medieval Crafting Stations Pack — 3 crafting stations.
- Medieval Props Pack — 19 settlement/interior props.

All three source pages explicitly list CC0.
