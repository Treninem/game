# Water and landscape source assets (CC0)

Real third-party source packs mirrored for later curation by the main game-development chat.

IMPORTANT: this directory is source/staging storage only. Nothing here is wired into Godot scenes, scripts, project settings, runtime resources, maps, or installer builds by this workflow.

Requested coverage:
- rivers / lakes / streams: reusable water-surface texture sources plus separate water meshes from the pond kit;
- ponds / swamps: pond kit, muddy/swamp water texture sources and marsh vegetation;
- reeds: dedicated low-poly reed model plus additional low-poly plant pack;
- water lilies / lily pads: two independent CC0 3D sources;
- bridges / small bridges: wooden, stone, concrete and modular bridge packs;
- suspension / hanging bridges: CC0 fantasy-RPG model pack explicitly tagged suspension + hanging + bridge;
- swings / playground: CC0 Playground archive with per-object glTF exports.

All mirrored sources listed below were selected from source pages that explicitly state CC0. Source URLs are retained for provenance.
