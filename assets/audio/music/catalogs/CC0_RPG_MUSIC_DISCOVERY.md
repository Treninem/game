# ImPuls — Verified CC0 RPG Music Discovery Catalog

Research/source catalog only. Nothing in this file is wired into runtime gameplay.

## Selection policy
- Prefer CC0 / public-domain music for commercial-safe reuse without mandatory attribution.
- Prefer loopable material and tracks with intro/loop/outro variants where available.
- Audition every candidate before production use; a title/tag is not enough to judge musical fit.
- Keep music sparse in exploration so environmental audio can carry the world.
- Do not mark a remote candidate as PHYSICAL until the actual audio file is stored or pinned through a repository source.

## Runtime intent for main development chat
Target a semantic adaptive system rather than one playlist. Music should react to threat, location, time, weather, story importance and recent playback history, while deliberately allowing long periods of silence/ambience-only gameplay.
