Selected Ranger.fbx with Ranger_Texture.png. Production GLB contains the skinned
human, clothing, cloak and fourteen source animation clips; the unused bow was
excluded. Height normalized to 1.80 m, feet at local ground zero, texture embedded.
The runtime faces the human along the movement direction and blends idle, walk,
run and punch clips. An airborne pose uses the same skeleton and physical jump.
This is an authored stylized human asset, not a photorealistic scan.
