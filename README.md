# ImPuls PC

Standalone offline single-player open-world survival RPG for Windows x64.

## Current milestone
Stage 0 — technical foundation.

## Core rules
- Offline gameplay first. Multiplayer/server systems are deferred.
- No paid APIs or credit-dependent runtime services.
- Free/open-source development stack where practical.
- Third-party assets require recorded source and compatible license.
- Modular architecture designed for long-term expansion.
- Releases are versioned and must not silently break saves.

## Engine
Godot 4.x stable. Engine/dependency upgrades are pinned and tested before adoption.

## Repository
This repository is the canonical source for ImPuls PC code and project metadata.
