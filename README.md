# ImPuls PC

Автономная одиночная 3D RPG на выживание в открытом мире для Windows x64.

## Текущий статус

ImPuls PC находится в активной разработке. В репозитории уже есть игровая техническая база, Windows-сборка, система сохранений и настроек, карта исследования мира, инфраструктура обновлений и отдельный загрузчик.

Текущая ветка `main` не должна считаться полностью проверенным стабильным релизом, пока обязательные игровые и релизные проверки CI не проходят успешно.

## Платформа и движок

- Windows x64.
- Godot 4.7.1 Stable.
- Рендерер Godot GL Compatibility.
- Основная сцена запуска: `scenes/main_menu.tscn`.
- Иконка и заставка ImPuls подключены через `assets/branding/impuls_icon.png`.

## Реализовано в проекте

### Сохранения

- 10 отдельных слотов сохранения.
- Создание новой игры в выбранном слоте.
- Загрузка существующего слота.
- Удаление сохранения.
- Хранение позиции и поворота игрока вместе с состоянием мира.
- Атомарная запись сохранений через временный файл.
- Резервная копия предыдущего сохранения и восстановление из неё при повреждении основного файла.
- Миграция старого одиночного сохранения в систему слотов.

### Настройки и управление

- Полноэкранный и оконный режим.
- Выбор разрешения.
- VSync.
- Масштаб 3D-рендера и интерфейса.
- Общая громкость, музыка, эффекты и отключение звука.
- Чувствительность мыши.
- Интервал автосохранения.
- FOV камеры.
- Субтитры.
- Переназначение клавиатуры и кнопок мыши.
- Управление движением, бегом, прыжком, взаимодействием, атакой, магией, быстрым использованием предметов, картой, инвентарём, журналом, крафтом, быстрым сохранением и загрузкой.

### Карта исследования мира

- Мир разбит на ячейки исследования.
- Открываются только посещённые игроком области и ближайшая зона вокруг него.
- Состояние исследованной карты сохраняется вместе с состоянием мира.
- Подсчитывается исследованная площадь и процент открытого мира.

## Установка и обновление

Для ImPuls создан отдельный `ImPuls-Launcher.exe`.

Загрузчик:

- устанавливает себя в `%LOCALAPPDATA%\Programs\ImPuls`;
- создаёт ярлык ImPuls на рабочем столе и в меню «Пуск»;
- получает последний опубликованный Windows-пакет из GitHub Releases;
- скачивает `ImPuls-PC-Windows-x64.zip`;
- проверяет SHA-256 скачанного пакета, если digest опубликован GitHub;
- распаковывает новую версию отдельно от установленной;
- заменяет игру только после проверки нового пакета;
- откатывает замену при ошибке переключения каталогов;
- запускает уже установленную игру офлайн, если сервер обновлений недоступен;
- самостоятельно проверяет и обновляет сам `ImPuls-Launcher.exe`.

Отдельный релиз загрузчика: `https://github.com/Treninem/game/releases/tag/launcher`.

## Сборка Windows

Windows-пайплайн проекта использует Godot 4.7.1 Stable и экспортные шаблоны той же версии. Перед публикацией стабильного установщика должны успешно пройти обязательные игровые smoke-тесты, проверки мира, движения игрока, интерфейса, экспорта и установщика.

## Основные правила разработки

- Сначала офлайн-геймплей. Мультиплеер и серверные системы — позже.
- Никаких платных API или сервисов, зависящих от кредитов.
- Бесплатный стек разработки и открытые технологии, где это возможно.
- Сторонние ресурсы используются только с проверенным источником и совместимой лицензией.
- Наличие ассета в staging не означает, что он уже интегрирован в игру.
- Модульная архитектура должна позволять расширять игру без полной переделки существующих систем.
- Обновления не должны приводить к потере пользовательских сохранений.
- Стабильный релиз нельзя публиковать только потому, что проект запускается или компилируется: обязательные release-gates должны быть зелёными.
